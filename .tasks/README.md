# TWallet Implementation Tasks

100 tasks across 6 phases to build the complete application.

## Phase 1 (001–015): Foundation
001–005: Project setup, TypeScript config, Tailwind theme, ESLint, path aliases
006–010: Auth pages (login, register, forgot/reset password, verify email)
011–015: Auth server actions, middleware, callback route, RLS basics

## Phase 2 (016–030): Backend
016–020: DB schema migrations (profiles, cards, orders, payments, notifications)
021–025: Edge Functions (verify-payment, order-status, webhook-blockchain, health-check)
026–030: Storage buckets, admin RLS policies, analytics views, audit triggers

## Phase 3 (031–040): Wallet & Payments
031–035: WalletConnect/wagmi provider, wallet connection UI, network switch
036–040: Payment checkout page, on-chain verification flow, payment polling

## Phase 4 (041–065): UI & Pages
041–045: Landing page sections (hero, features, stats, CTA, footer)
046–050: Dashboard layout, sidebar, header, overview, order list
051–055: Card catalog, wallet page, transaction history, notifications, profile
056–060: Admin dashboard layout, overview, users, orders, payments
061–065: Admin cards, settings, audit logs, public pages, support pages

## Phase 5 (066–080): Integration
066–070: Unit tests, integration tests, E2E tests, MSW handlers, test setup
071–075: Performance optimization, accessibility audit, responsive design
076–080: Security audit, rate limiting, email notifications, CI pipeline

## Phase 6 (081–100): Deployment
081–085: Vercel config, env vars, domain setup, SSL, production DB
086–090: Sentry monitoring, uptime monitoring, backup strategy, rollback plan
091–095: Load testing, SEO audit, content security headers, PWA manifest
096–100: Launch checklist, documentation finalization, post-launch monitoring
